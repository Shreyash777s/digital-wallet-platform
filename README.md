# Digital Wallet Platform

A production-style full-stack digital wallet and payment platform.

## Technology Stack

- .NET 8
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- Angular
- JWT Authentication
- Docker
- GitHub Actions

## Modules

- Identity and Authentication
- KYC
- Wallet Management
- Ledger
- Add Money
- Transfers
- Withdrawals
- Merchant Payments
- Refunds
- Disputes
- Risk Management
- Reconciliation
- Reporting
- Audit Logging

## Applications

- Customer Portal
- Operations Portal

## Development Approach

The project is developed incrementally using sprints.
Each sprint includes backend development, frontend integration,
testing, and deployment.s
